* Journal de recherche — Modélisation 3D d'une PEMFC avec Dedalus

** Vision générale du projet

L'objectif du projet est de construire progressivement un modèle numérique
multiphysique d'une pile PEMFC, suffisamment détaillé pour représenter les
mécanismes physiques importants tout en restant numériquement contrôlable.

Le système cible est une pile de type Ballard 200 W, à cathode ouverte et anode
hydrogène en mode dead-end avec purge périodique.

L'objectif final n'est pas simplement d'obtenir une courbe courant-tension.
Le but est de construire un modèle capable de représenter spatialement et
dynamiquement les phénomènes suivants :

- transport de l'oxygène dans la cathode ;
- diffusion dans la GDL ;
- transport dans la couche catalytique ;
- réaction électrochimique ORR ;
- conduction électronique dans la phase solide ;
- conduction protonique dans l'ionomère ;
- hydratation de la membrane ;
- diffusion de l'eau dans la membrane ;
- électro-osmose ;
- rétro-diffusion de l'eau ;
- échanges d'eau avec l'anode ;
- fonctionnement dead-end de l'anode ;
- purge périodique ;
- accumulation éventuelle d'eau liquide ;
- transport thermique ;
- refroidissement par l'air de la cathode ouverte ;
- influence du débit d'air ;
- couplage avec la température ;
- à terme, phénomènes transitoires complets.

L'idée directrice est de ne jamais introduire toute la physique en une seule
fois.

Une simulation multiphysique complexe peut donner des résultats visuellement
plausibles tout en étant fausse pour des raisons numériques ou conceptuelles.
Le développement doit donc progresser par niveaux, chaque nouveau mécanisme
étant testé indépendamment avant d'être couplé aux précédents.

Principe méthodologique retenu :

  physique simple
  → tests unitaires
  → simulation courte
  → validation physique
  → convergence numérique
  → ajout d'une nouvelle physique

Chaque version doit posséder une limite identifiable permettant de retrouver
la version précédente.

Cela permet de distinguer :

- une vraie conséquence physique ;
- un changement dû à un paramètre ;
- un problème de convergence ;
- un artefact de discrétisation ;
- une erreur d'implémentation.

** Système physique de référence

Le modèle est construit autour d'une pile de type FCgen / FCvelocity 1020ACS.

Les données utilisées proviennent autant que possible du manuel Ballard.

Données de référence disponibles :

- puissance nominale : environ 200 W ;
- courant de fonctionnement considéré : environ 26.04 A ;
- nombre de cellules provisoire : 10 ;
- tension cellule nominale utilisée : environ 0.768 V ;
- température optimale au point nominal :
    T_opt ≈ 39.81 °C ;
- cathode ouverte ;
- refroidissement assuré par le flux d'air cathodique ;
- anode hydrogène dead-end ;
- purge périodique ;
- volume de purge :
    environ 20 mL par cellule,
    soit environ 200 mL pour 10 cellules ;
- intervalle de purge dérivé du manuel :
    environ 2300 A.s ;
- au point nominal :
    période de purge ≈ 88.3 s.

Le manuel donne également une relation empirique pour la température optimale :

  T_opt [°C] = 26.01 + 0.53 I

Au courant nominal :

  I = 26.04 A

donc :

  T_opt ≈ 39.81 °C

Le débit stœchiométrique d'air nécessaire à la réaction est beaucoup plus faible
que le débit réellement utilisé dans une cathode ouverte.

Une distinction importante a donc été introduite entre :

- débit d'air nécessaire à l'oxygène ;
- débit d'air nécessaire au refroidissement.

Le seuil d'air calculé initialement autour de 216 slpm correspond à un choix
conservatif de stœchiométrie élevée et ne doit pas être interprété comme le
débit physique exact du ventilateur.

** Choix de Dedalus

Dedalus a été choisi comme infrastructure de résolution.

Motivations :

- formulation spectrale ;
- bonne adaptation aux PDE multiphysiques ;
- possibilité de domaines 1D, 2D et 3D ;
- prise en charge MPI ;
- possibilité d'ajouter progressivement les champs physiques ;
- contrôle relativement explicite des équations.

Environnement :

- Debian 13 ;
- Python 3.13 ;
- Dedalus 3.0.5 ;
- mpi4py ;
- OpenMPI.

La machine principale utilisée pour les calculs est le m710s.

Les premiers benchmarks montrent que :

- 4 processus MPI correspondent aux quatre cœurs physiques ;
- 8 processus sont possibles avec les threads logiques ;
- 8 processus diminuent légèrement le temps mur ;
- 4 processus restent meilleurs en efficacité CPU.

Pour les études longues, priorité donnée au temps mur :

  MPI_N = 8

avec :

  OMP_NUM_THREADS=1
  NUMEXPR_NUM_THREADS=1

** Stratégie de construction du modèle

Le plan initial de développement est découpé en étapes.

*** Étape 1 — transport d'oxygène seul

Construire un domaine cathodique 3D simple.

Objectifs :

- vérifier Dedalus ;
- vérifier la géométrie ;
- tester MPI ;
- vérifier les conditions aux limites ;
- établir un premier pipeline de résultats ;
- créer les premiers tests.

*** Étape 2 — électrochimie

Ajouter :

- potentiel électronique phi_s ;
- potentiel protonique phi_m ;
- surtension ;
- réaction Butler-Volmer ;
- consommation d'oxygène.

Objectif :

obtenir un système cathodique couplé transport + électrochimie.

*** Étape 3 — membrane hydratée

Isoler d'abord la membrane en 1D.

Ajouter :

- teneur en eau lambda ;
- conductivité protonique dépendant de lambda ;
- électro-osmose ;
- diffusion de l'eau ;
- relation Springer.

Objectif :

valider séparément la physique de membrane avant de la coupler au modèle 3D.

*** Étape 4 — hydratation cathodique

Relier l'humidité cathodique à la conductivité protonique de la couche
catalytique.

Objectif :

introduire un premier lien entre l'état hydrique et l'électrochimie.

*** Étape 5 — couplage membrane / cathode

Faire communiquer :

  cathode 3D
  ↕
  membrane 1D

Objectif :

faire dépendre la tension protonique interfaciale de la résistance réelle de la
membrane.

*** Étape 6 — eau côté anode

Abandonner progressivement l'hypothèse simplifiée de flux d'eau nul côté anode.

Objectif :

faire apparaître un vrai drainage ou une vraie accumulation d'eau côté anode.

** V0.1 — Cathode 3D avec transport d'oxygène

La première version devait rester volontairement minimale.

Le domaine représente un petit patch de cathode :

  Lx = 2 mm
  Ly = 1 mm

avec :

- GDL ≈ 200 µm ;
- couche catalytique ≈ 12 µm.

Ces dimensions internes ne proviennent pas du manuel Ballard.
Elles sont des hypothèses explicites de modélisation.

Le domaine utilise :

- Fourier réel dans x ;
- Fourier réel dans y ;
- Chebyshev dans z.

La première physique introduite est la concentration en oxygène.

Le transport est diffusif avec des coefficients effectifs différents dans :

- la GDL ;
- la couche catalytique.

La réaction est représentée initialement par un puits pseudo-premier ordre.

Cette version n'a pas vocation à être physiquement complète.

Son rôle est essentiellement numérique :

- vérifier le maillage ;
- vérifier les sorties HDF5 ;
- vérifier MPI ;
- contrôler les temps de calcul ;
- construire les premiers outils de validation.

Premier enseignement :

la stratégie consistant à construire un modèle simple avant de complexifier le
système fonctionne bien avec Dedalus.

** V0.2 — Couplage transport / électrochimie

La version suivante ajoute trois champs principaux :

- c_O2 ;
- phi_s ;
- phi_m.

La réaction est remplacée par une formulation électrochimique de type
Butler-Volmer.

La surtension locale est construite à partir de :

  eta = phi_s - phi_m - E_eq

La réaction volumique ORR dépend :

- de la surtension ;
- de la concentration en oxygène ;
- d'un courant d'échange volumique j0.

Le courant d'échange utilisé reste un paramètre de calibration.

La microstructure réelle de la couche catalytique n'étant pas connue,
l'objectif n'est pas encore de prédire exactement la pile Ballard.

*** Problème de signe dans l'équation protonique

Une erreur importante a été identifiée au cours du développement.

La relation :

  i_m = -sigma_m grad(phi_m)

et la consommation de protons par l'ORR donnent :

  div(i_m) = -j_ORR

donc :

  div(sigma_m grad(phi_m)) = +j_ORR

Le signe initial utilisé dans la pseudo-dynamique protonique était incorrect.

Cette erreur a été corrigée dans V0.2 puis répercutée dans les versions
suivantes.

Cet épisode a confirmé l'importance de vérifier les équations à partir des lois
de conservation plutôt que de se fier uniquement à la stabilité numérique.

*** Convergence spatiale V0.2

Trois grilles ont été étudiées :

  8×8×24
  12×12×36
  16×16×48

Résultats principaux après correction :

8×8×24 :
  c_O2 ≈ 7.45632

L'écart de grille devient faible.

La convergence numérique apparaît suffisante pour utiliser 16×16×48 comme
grille standard intermédiaire.

** V0.3 — Membrane hydratée 1D

Avant de coupler l'eau au modèle 3D, décision prise de développer une membrane
1D séparée.

Cette étape permet de vérifier indépendamment :

- hydratation ;
- conductivité ;
- électro-osmose ;
- diffusion.

*** Teneur en eau

La relation Springer est utilisée :

  lambda(a) =
    0.043
    + 17.81 a
    - 39.85 a²
    + 36 a³

avec :

  0 <= a <= 1

où a représente l'activité de l'eau.

*** Conductivité protonique

La conductivité dépend fortement de lambda.

Relation de type Springer :

  sigma =
    (0.005139 lambda - 0.00326)
    exp[1268 (1/303 - 1/T)]

La relation initiale est exprimée en S/cm puis convertie en S/m.

Cette dépendance est essentielle :

  membrane sèche
  → conductivité faible
  → résistance élevée
  → perte ohmique importante.

*** Electro-osmose

Le coefficient de drag est pris comme :

  n_drag = lambda / 22

Le courant protonique transporte donc de l'eau de l'anode vers la cathode.

En parallèle, la diffusion peut transporter l'eau dans le sens opposé.

Le bilan entre :

- électro-osmose ;
- diffusion ;

détermine le profil d'hydratation dans la membrane.

*** Résultats V0.3

Avec une grille membrane fine :

  nz = 64

on obtient notamment :

  lambda_mean ≈ 1.7246
  sigma_mean ≈ 0.6718 S/m

La solution est stable et convergée.

Cette étape valide les relations constitutives avant leur utilisation dans le
couplage complet.

** V0.4 — Cathode 3D hydratée

La V0.4 introduit une première dépendance de l'électrochimie à l'humidité.

La RH cathodique est transformée en teneur en eau via Springer.

Cette valeur est utilisée pour ajuster la conductivité protonique de la couche
catalytique.

Ce modèle reste simplifié :

la membrane n'est pas encore résolue dynamiquement dans le modèle cathodique.

La RH impose essentiellement un état d'hydratation représentatif de la CL.

** V0.5 — Couplage membrane / cathode

La V0.5 marque un changement important.

Jusqu'ici, l'hydratation de la membrane n'influençait pas directement la
condition de potentiel protonique appliquée à la cathode.

L'idée est alors de construire un couplage partitionné :

  cathode 3D
  → courant
  → membrane 1D
  → ASR membrane
  → chute de potentiel protonique
  → nouvelle cathode 3D

Le processus est itératif.

*** Algorithme de couplage

À chaque itération :

1. résoudre la cathode 3D ;
2. intégrer le courant ;
3. calculer la densité de courant :

     J = I / A

4. calculer l'électro-osmose ;
5. calculer le profil lambda(z) ;
6. calculer sigma(lambda) ;
7. intégrer l'ASR membrane :

     ASR = integral dz / sigma

8. calculer la cible :

     phi_m,target = -J ASR

9. relaxer :

     phi_m,next =
       (1-r) phi_m
       + r phi_m,target

10. recommencer jusqu'à convergence.

La V0.5 est donc un couplage :

  quasi-stationnaire
  partitionné
  à point fixe.

Ce n'est pas encore un modèle monolithique.

*** Première tentative de condition anodique

Une première idée consistait à imposer une hydratation anodique fixe,
correspondant à une alimentation sèche.

Cette approche donne une membrane beaucoup trop sèche et une résistance
anormalement élevée.

Décision :

ne pas utiliser une valeur fixe arbitraire de lambda côté anode.

*** Hypothèse zéro-flux

La condition retenue pour V0.5 est :

  flux d'eau net à l'anode = 0

entre deux purges.

Dans le modèle stationnaire :

  J_water =
    -D d(lambda)/dz
    + v lambda

avec :

  J_water = 0

La solution devient exponentielle.

Cette approximation représente une anode dead-end idéale entre deux événements
de purge.

Elle permet notamment à la rétro-diffusion cathode → anode de maintenir
l'hydratation côté anode.

Mais elle reste volontairement simplifiée.

*** Premier résultat nominal

Au point :

  RH cathode = 0.5
  V = 0.768 V

V0.5 donne environ :

  I = 2.17 mA
  J = 1086 A/m²
  ASR ≈ 3.12e-5 ohm m²
  lambda_anode ≈ 3.25
  lambda_mean ≈ 3.37

Comparé à V0.4, le courant diminue fortement.

Cette baisse provient essentiellement de l'introduction explicite de la chute
ohmique de la membrane.

Ce résultat montre qu'une membrane représentée seulement par une conductivité
locale dans la CL sous-estime fortement les pertes protoniques globales.

*** Sweep V0.5 RH / tension

Une matrice 3×3 est étudiée.

  0.5
  0.9

Tension :

  0.70 V
  0.768 V
  0.83 V

9 cas.

Tous convergent.

Résultat général :

la pénalité membrane est plus forte :

- à faible RH ;
- à forte charge.

Exemples de réduction de courant V0.4 → V0.5 :

  V=0.70  → environ -67.5 %
  V=0.768 → environ -48.7 %
  V=0.83  → environ -28.5 %

RH 50 % :
  V=0.70  → environ -63.8 %
  V=0.768 → environ -43.5 %
  V=0.83  → environ -23.8 %

  V=0.70  → environ -44.8 %
  V=0.768 → environ -22.8 %
  V=0.83  → environ -9.4 %

Interprétation :

à forte charge, le courant protonique augmente.

Donc :

  J ↑
  → chute ohmique J·ASR ↑
  → phi_m plus négatif
  → surtension cathodique moins favorable
  → courant ↓

À faible RH, l'ASR est également plus élevée.

Les deux effets se renforcent.

** Réflexion après V0.5

À ce stade, le modèle contient déjà :

- cathode 3D ;
- diffusion O2 ;
- potentiel électronique ;
- potentiel protonique ;
- ORR ;
- hydratation de la membrane ;
- électro-osmose ;
- rétro-diffusion ;
- résistance membrane ;
- couplage cathode / membrane.

Mais une hypothèse devient clairement limitante :

  J_water,anode = 0

Cette condition suppose qu'aucune eau ne quitte la membrane par l'anode entre
les purges.

Physiquement, cela est trop restrictif.

Même en mode dead-end, l'anode peut échanger de l'eau avec :

- le gaz ;
- les parois ;
- le volume anodique ;
- la purge ;
- éventuellement un flux résiduel.

La prochaine version doit donc introduire une condition de transfert d'eau
anodique finie.

** V0.6 — Transport d'eau côté anode

Objectif :

remplacer :

  J_water,anode = 0

par :

  -J = k_a (lambda_anode - lambda_eq,anode)

où :

  k_a
  = coefficient de transfert d'eau côté anode ;

  lambda_eq,anode
  = hydratation d'équilibre imposée par RH_anode.

Cette condition est de type Robin.

Elle représente un échange fini entre :

- membrane ;
- environnement anodique.

*** Raisonnement derrière cette condition

On veut conserver deux propriétés essentielles.

Premièrement :

  k_a = 0

doit redonner exactement V0.5.

Cela fournit une limite de continuité extrêmement utile pour la validation.

Deuxièmement :

si :

  lambda_anode > lambda_eq,anode

alors l'eau doit quitter la membrane.

Le flux de retrait est donc positif.

Cette condition introduit une nouvelle physique tout en conservant un contrôle
direct sur son intensité.

*** Paramètre k_a

Valeur provisoire choisie :

  k_a = 2e-6 m/s

Cette valeur n'est pas donnée par Ballard.

Elle est volontairement considérée comme :

  paramètre de modèle

et non :

  donnée expérimentale.

La logique actuelle n'est pas de rechercher immédiatement la "bonne valeur".

Il faut d'abord vérifier que le modèle répond correctement lorsqu'on fait varier
k_a.

*** Tests unitaires V0.6

Les tests vérifient notamment :

- k_a = 0 reproduit exactement la condition V0.5 ;
- k_a > 0 draine la membrane ;
- la limite sans drag électro-osmotique est correcte ;
- le flux de retrait est positif lorsque lambda_anode > lambda_eq.

Tous les tests passent.

*** Driver V0.6

Un driver séparé est créé.

V0.5 reste donc intacte.

Paramètres nouveaux :

  --anode-relative-humidity
  --anode-water-transfer-coefficient

Les résultats enregistrent maintenant :

- lambda_anode ;
- lambda_mean ;
- ASR ;
- sigma ;
- flux d'eau anodique.

secondaire.

  lambda_eq,anode

dans la condition de Robin.

Elle peut donc changer non seulement l'intensité mais également le sens du
transfert d'eau.

  lambda_anode > lambda_eq,anode

La conséquence électrique dépend ensuite du niveau absolu d'hydratation et du
courant.

Le régime dry_high_load bénéficie donc fortement de l'humidification anodique,
alors que le régime wet_low_load est déjà suffisamment hydraté pour que
l'effet sur le courant reste limité.

** V0.7 — Volume anodique dynamique

La V0.6 a validé la condition de transfert d'eau anodique sur trois axes :

- sensibilité à k_a ;
- convergence spatiale ;
- sensibilité à RH_anode.

La limitation principale devient maintenant structurelle :

  RH_anode

est encore imposée comme une condition externe.

Pour une anode dead-end, cette humidité doit au contraire émerger d'un bilan de
matière dans un volume gazeux fini.

La V0.7 commence donc par introduire explicitement un inventaire d'eau anodique
dynamique.

*** Stratégie incrémentale

Comme pour les versions précédentes, la dynamique complète de l'anode n'est pas
introduite en une seule étape.

Le premier incrément V0.7 isole uniquement :

  membrane
  -> flux d'eau
  -> volume anodique fini
  -> RH_anode dynamique.

Le transport H2, la consommation d'hydrogène, la variation de pression, l'azote
et la purge transitoire restent volontairement hors de ce premier sous-modèle.

L'objectif est d'abord de vérifier le bilan d'eau et son échelle de temps.

*** Fermeture quasi-stationnaire utilisée

La campagne V0.6 de sensibilité à RH_anode fournit, pour chaque régime, une
relation tabulée :

  RH_anode
  -> flux d'eau membrane/anode.

Cette relation validée est utilisée comme fermeture quasi-stationnaire par
interpolation linéaire.

Cela permet d'étudier la dynamique du volume anodique sans relancer une
simulation cathodique 3D à chaque pas de temps.

Cette V0.7 initiale est donc un modèle réduit dynamique construit à partir de la
réponse V0.6 validée.

*** Conversion du flux membrane vers le volume gazeux

Le flux V0.6 est exprimé en espace lambda :

  J_lambda [lambda m/s].

Il est converti en débit molaire d'eau par :

  n_dot_H2O = J_lambda * A * c_fixed

où :

  A
  = aire du patch membrane ;

  c_fixed
  = concentration molaire des sites fixes de la membrane.

La convention de signe est conservée :

  n_dot_H2O > 0
  -> eau entrant dans le volume anodique ;

  n_dot_H2O < 0
  -> eau quittant le volume anodique vers la membrane.

*** Volume anodique provisoire

Le volume gazeux interne réel du stack n'est pas fourni par le manuel Ballard.

Une hypothèse explicite est donc introduite :

  V_anode = 20 mL par cellule représentative.

Cette valeur est numériquement égale au volume de purge par cellule donné dans
le manuel, mais elle ne doit pas être interprétée comme une mesure du volume
interne des canaux.

Elle sert uniquement d'échelle provisoire pour la première dynamique.

Une sensibilité à ce volume sera nécessaire ultérieurement.

*** État thermodynamique de l'eau

Le premier modèle V0.7 suppose :

- température anodique uniforme égale à la température stack ;
- volume constant ;
- équilibre vapeur/liquide instantané ;
- gaz idéal pour la vapeur d'eau.

La pression de vapeur saturante est obtenue par une corrélation de Buck.

Lorsque l'inventaire total d'eau dépasse la capacité de vapeur saturée :

  RH_anode = 1

et l'excès est stocké comme eau liquide dans l'inventaire du volume.

Ce traitement ne constitue pas encore un modèle d'eau liquide dans les canaux.
Il évite simplement de créer une humidité relative supérieure à 100 %.

*** Validation attendue

Le premier test dynamique part d'une anode sèche :

  RH_anode(t=0) = 0.

La V0.6 donne un flux positif dans les trois régimes à cette condition.

Le volume anodique doit donc s'humidifier progressivement.

À mesure que RH_anode augmente, le flux de transfert doit diminuer puis tendre
vers zéro.

Le point fixe dynamique doit être cohérent avec les inversions de flux observées
en V0.6, soit approximativement :

  dry_high_load : RH_anode ≈ 0.255
  nominal       : RH_anode ≈ 0.434
  wet_low_load  : RH_anode ≈ 0.883.

Ce rapprochement entre :

  zéro de la fermeture statique V0.6

et :

  état stationnaire du volume dynamique V0.7

constitue la première validation de continuité entre les deux versions.

*** Consommation électrochimique

La consommation molaire d'hydrogène est calculée par la loi de Faraday :

  n_dot_H2,cons = I / (2 F).

Le courant utilisé à chaque instant provient de la même fermeture V0.6 que le

  RH_anode
  -> courant
  -> flux d'eau.

*** Pression et mélange gazeux

Le mélange gazeux actuel contient uniquement :

- H2 ;
- vapeur d'eau.

Les pressions partielles utilisent le gaz parfait :

  p_i = n_i R T / V.

La pression totale est :

  p_total = p_H2 + p_H2O.

L'azote n'est pas encore représenté.

*** Alimentation H2 provisoire

Le manuel Ballard donne une pression H2 optimale :

  0.36 barg.

Avec la pression atmosphérique de référence :

  101325 Pa

le modèle utilise donc une cible absolue :

  p_target = 137325 Pa.

L'alimentation est représentée par un régulateur idéal unidirectionnel.

À chaque pas :

1. H2 est consommé électrochimiquement ;
2. l'état d'eau est mis à jour ;
3. le régulateur peut ajouter du H2 pour remonter à la pression cible ;
4. le régulateur ne peut jamais retirer de gaz.

Cette dernière propriété est essentielle pour représenter qualitativement une
anode dead-end.

Si l'accumulation de vapeur d'eau suffit à maintenir ou dépasser la pression
cible, l'entrée H2 se ferme.

Une surpression peut donc apparaître puisque la purge n'existe pas encore.

*** Limites explicites

Ce sous-modèle ne représente pas encore :

- la dynamique mécanique réelle du détendeur ;
- une loi de débit fondée sur une perte de charge ;
- la composition en azote ;
- le crossover d'azote ;
- la dépendance de l'électrochimie à p_H2 ;
- une chute de pression le long des canaux ;
- la purge.

Le régulateur idéal sert uniquement à fermer proprement le bilan de matière H2
avant d'ajouter ces phénomènes.

*** Modèle de purge

Le volume anodique est traité comme un volume parfaitement mélangé.

Pour un volume échangé V_purge, la fraction du gaz initial retirée est :

  f_purge = 1 - exp(-V_purge / V_anode).

Avec les valeurs provisoires actuelles :

  V_purge = 20 mL
  V_anode = 20 mL

on obtient :

  f_purge ≈ 0.6321.

Une purge retire cette même fraction de :

- H2 ;
- vapeur d'eau.

L'eau liquide n'est pas expulsée directement dans ce premier modèle.

Après retrait du gaz, l'équilibre vapeur/liquide est recalculé.

Le régulateur H2 idéal recharge ensuite uniquement la quantité d'H2 nécessaire
pour revenir à la pression totale cible.

2. recharge H2 par le régulateur.

intermédiaire artificiel.

- l'amplitude réelle de la chute de pression ;
- la quantité réelle de H2 expulsée ;
- le rendement H2 associé à la purge.

*** Débit de sortie dépendant de la pression

Le débit sortant est représenté par une conductance linéaire :

  n_dot_out = C_purge * max(p_anode - p_amb, 0).

La conductance est calibrée pour retrouver le débit minimal Ballard :

  2.4 slpm par cellule

lorsque :

  p_anode = 137325 Pa
  p_amb   = 101325 Pa.

La conversion slpm -> mol/s suppose, pour cette première fermeture :

  1 atm
  273.15 K

comme conditions standard.

Cette loi est volontairement simple.

Elle garantit néanmoins que :

- aucun débit sortant n'existe sous la pression ambiante ;
- le débit augmente avec la surpression ;
- la pression n'est plus imposée par un retrait instantané arbitraire.

*** Alimentation H2 pendant la purge

Le régulateur H2 reste actif pendant l'ouverture.

À chaque pas de purge :

1. le transfert d'eau membrane -> anode est intégré ;
2. H2 est consommé électrochimiquement ;
3. le débit sortant est calculé à partir de la pression instantanée ;
4. le mélange gazeux sort avec la composition H2/H2O du volume ;
5. la pression après écoulement est évaluée ;
6. le régulateur ajoute ensuite du H2 si nécessaire pour revenir vers la
   pression cible.

Le régulateur reste idéal dans cet incrément.

La nouveauté est donc principalement :

  sortie gazeuse résolue dans le temps
  +
  alimentation simultanément active.

** V0.7 — Mise à l'échelle aire active / cellule

La purge transitoire a validé la dynamique événementielle et les bilans, mais
les quantités absolues restaient incohérentes parce que le modèle mélangeait :

- un patch numérique de 2 mm x 1 mm ;
- un courant de patch de quelques mA ;
- un volume anodique de 20 mL par cellule ;
- un débit de purge de 2.4 slpm par cellule.

La V0.7 introduit maintenant une calibration d'aire active afin de placer le
courant, le transfert d'eau, le volume anodique et la purge sur une même échelle
cellulaire.

*** Principe

Au point nominal de calibration :

  regime = nominal
  RH_anode = 0

le modèle fournit un courant intégré sur le patch :

  I_patch,ref.

La densité de courant représentative est :

  j_ref = I_patch,ref / A_patch.

L'aire active cellulaire est ensuite inférée par :

  A_active = I_cell,ref / j_ref

avec :

  I_cell,ref = 26.04 A.

Le facteur d'échelle est donc :

  S_A = A_active / A_patch
      = I_cell,ref / I_patch,ref.

Cette aire est une calibration dérivée du modèle, pas une mesure géométrique du
stack Ballard.

*** Application du facteur d'échelle

Le facteur S_A est appliqué à deux grandeurs auparavant définies au niveau du
patch :

1. courant intégré :

     I_cell = S_A * I_patch

   pour la consommation électrochimique de H2 ;

2. aire membrane :

     A_membrane = A_active

   pour convertir le flux lambda en débit molaire d'eau.

Le volume anodique :

  20 mL

et le débit de purge :

  2.4 slpm

restent définis par cellule.

La loi de purge à :

  2300 A.s

continue d'utiliser le courant cellulaire nominal de :

** V0.7 — Inventaire N2 et crossover cathode -> anode

La chaîne de purge standard est maintenant suffisamment cohérente pour ajouter

- la contribution de N2 à la pression totale ;
- la dilution molaire de H2 ;
- l'évacuation de N2 pendant la purge ;
- la fermeture du bilan de matière N2.

*** Source de crossover

Le crossover est représenté par un flux surfacique imposé :

  J_N2 [mol/m2/s].

Le débit molaire vers l'anode vaut :

  n_dot_N2 = J_N2 * A_active.

La valeur de screening utilisée initialement est :

  J_N2 = 1e-6 mol/m2/s.

Cette valeur est une hypothèse provisoire de modèle.

Elle n'est pas issue d'une calibration Ballard et ne doit pas être interprétée
comme une mesure de perméabilité de la membrane.

Le premier objectif est la validation conservative du nouvel état N2.

*** État gazeux anodique

Le volume contient maintenant explicitement :

- H2 ;
- N2 ;
- vapeur d'eau ;
- éventuellement eau liquide dans l'inventaire hydrique déjà existant.

La pression totale est calculée par :

  p_total = (n_H2 + n_N2 + n_H2O,vap) R T / V.

Le régulateur H2 tient compte de N2 et de H2O lors du calcul de la quantité de
H2 nécessaire pour revenir vers la pression cible.

*** Purge standard

Le nouvel incrément conserve la configuration désormais retenue comme référence
quantitative :

  durée = 0.5 s
  débit de référence = 2.4 slpm
  déclenchement = intégrale de I_cell(t) jusqu'à 2300 A.s.

Pendant la purge, le débit sortant retire le mélange gazeux parfaitement
mélangé selon ses fractions molaires instantanées :

  H2
  N2
  H2O.

Le bilan N2 devient :

  n_N2,crossover
  - n_N2,purge
  - n_N2,final
  ≈ 0.

*** Pas de rétroaction électrochimique dans ce premier incrément

Le courant reste obtenu à partir de la fermeture V0.6 :

  RH_anode -> courant.

Ni :

  p_H2

ni :

  x_H2

ne modifient encore la cinétique électrochimique.

Cette séparation est volontaire afin de distinguer :

1. validation du transport et du bilan N2 ;
2. rétroaction électrochimique due à la dilution H2.

** V0.7 — Première rétroaction électrochimique de la dilution H2

La sensibilité au crossover N2 a montré que la dilution reste modérée pour les
flux faibles, mais devient de quelques pourcents dans le régime wet_low_load
pour les valeurs de screening les plus élevées.

Le modèle introduit maintenant une première rétroaction électrochimique simple,
sans modifier la fermeture RH de V0.6 elle-même.

*** Loi de rétroaction

Le courant issu de V0.6 est multiplié par :

  f_H2 = (p_H2 / p_H2,ref)^gamma

avec :

  I = I_V0.6 * f_H2.

La pression de référence p_H2,ref est évaluée au même état hydrique mais avec :

  n_N2 = 0.

Cette normalisation est importante : elle évite de compter une seconde fois
l'effet de l'humidité déjà inclus dans la fermeture V0.6.

Ainsi, le facteur ne représente que la perte supplémentaire liée à la dilution
de H2 par N2.

*** Exposant de sensibilité

L'exposant :

  gamma

est un paramètre de screening.

La campagne étudie :

  gamma = 0
  gamma = 0.5
  gamma = 1.

Le cas :

  gamma = 0

désactive exactement la rétroaction et doit reproduire la campagne N2
précédente.

Les cas 0.5 et 1 encadrent une réponse sous-linéaire et linéaire à la pression
partielle H2.

Cette loi n'est pas présentée comme un modèle cinétique HOR calibré.

Elle sert à mesurer la sensibilité de la dynamique couplée à une première
rétroaction explicite.

*** Flux de crossover étudiés

La campagne utilise :

  J_N2 =
    0
    1e-6
    2e-6
    5e-6 mol/m2/s.

Le cas J_N2 = 0 doit donner :

  f_H2 = 1

même lorsque gamma > 0.

Il constitue donc un deuxième test de continuité indépendant de gamma = 0.

*** Boucle de couplage introduite

Le système contient maintenant la boucle :

  RH_anode
  -> courant V0.6
  -> facteur f_H2
  -> courant cellule corrigé
  -> consommation H2
  -> intégrale de courant
  -> fréquence de purge
  -> accumulation N2
  -> p_H2
  -> facteur f_H2.

La purge n'est donc plus strictement indépendante de N2 dès que gamma > 0.

Une diminution du courant peut :

- allonger la période de purge ;
- augmenter l'accumulation N2 ;
- réduire encore p_H2.

Cette rétroaction doit rester monotone et stable sur la plage étudiée.

*** Décision de développement

La rétroaction électrochimique réduite reste modérée sur la plage de screening,
mais elle affecte déjà la fréquence de purge dans le régime wet_low_load.

La prochaine étape physique peut maintenant être choisie entre :

- une loi de dépendance à p_H2 mieux fondée physiquement ;
- ou l'introduction d'une vraie loi de crossover N2 dépendant des pressions
  partielles de part et d'autre de la membrane.

La seconde option est préférable pour progresser vers un modèle de transport
plus physique sans multiplier trop tôt les paramètres cinétiques empiriques.

La prochaine étape retenue est donc :

  crossover N2 dépendant du gradient de pression partielle.

Le flux imposé constant sera remplacé par une loi de type :

  J_N2 = K_N2 * max(p_N2,cathode - p_N2,anode, 0)

avec K_N2 paramétrique dans un premier temps.

Cette évolution permettra de faire décroître naturellement le crossover lorsque
N2 s'accumule à l'anode, au lieu d'imposer une source constante indépendante de
l'état interne.
